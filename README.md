# git-practice

Git 与 GitHub 工作流练习仓库，用来熟悉分支、提交、PR 与合并的完整流程。

## 快速开始

```bash
git clone git@github.com:zhuguhe789-crypto/git-practice.git
cd git-practice
git lg
```

## 项目结构

```text
git-practice/
├── README.md      # 项目说明
└── .gitignore     # 忽略规则
```

## 方法说明

按「建分支 → 小步提交 → 发 PR → 自查 → squash 合并」的流程推进。

## 结果

已完成首次提交与推送，分支与 PR 记录见提交历史。
